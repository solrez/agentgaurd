7 validators. Every angle covered.

From schema checks to LLM-powered hallucination detection. Mix and match what you need.

{}

Schema Validator

Catches hallucinated endpoints, missing fields, and wrong types. If the agent invents an API that doesn't exist, it gets blocked.

!

Safety Scorer

Detects DROP TABLE, rm -rf, and other destructive patterns. Risk-scores every action and blocks anything above your threshold.

#

Rate Limiter

Sliding window rate limiting per target and globally. Stops runaway agents from hammering APIs or looping endlessly.

~

Trajectory Validator

Tracks multi-step workflows. Detects repeated actions, cascading errors, and goal drift across agent sessions.

<>

Code Validator

AST-based static analysis catches dangerous imports, eval/exec calls, and unsafe code patterns before execution.

?

Semantic Checker

LLM-powered hallucination detection. Cross-references agent actions against your grounding documents to catch fabricated data.
